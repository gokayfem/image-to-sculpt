# Changelog

## [0.1.0] — 2026-11-08

First version.

- An agent skill that turns one image of any subject into a recorded, measured sculpt: front maps, generated or
  imported views with whole-circle registration and screening, a recorded visual hull, map-fitting passes
  (forms, surface, detail, polish, focus), silhouette cuts and openings, exact signed distance fields throughout.
- `i2s.py` CLI with case scaffolding, a fal budget ledger, map checks and sheets, Blender replay, timelapse and
  turntable films, GLB/OBJ/STL exports, a report and a review page; `demo` runs the whole pipeline offline on a
  synthetic subject.
- Tests against closed forms and synthetic subjects with known shape (wrong view angles, noisy normals, a view
  with a changed pose).
- Adapters for Claude Code, Codex, Cursor, Copilot, Gemini CLI and chat assistants.
